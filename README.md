# Survey Form

A basic HTML & CSS project built as part of the freeCodeCamp Responsive Web Design Certification. This form collects user responses with input fields, radio buttons, checkboxes, and a submit button. The layout is fully responsive.

## 🔗 Live Demo
[Live Link](https://fcc-survey-form-reetu-2025.netlify.app/)

## 🛠️ Tech Stack
- HTML5
- CSS3

## 🧠 Purpose
This project was created to practice form structure, input types, labels, and basic responsive behavior. It reinforced semantic HTML and proper accessibility techniques.
